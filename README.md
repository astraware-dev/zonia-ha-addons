# Zonia Add-ons para Home Assistant

[![Agregar repositorio](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fastraware-dev%2Fzonia-ha-addons)

En Home Assistant: **Ajustes → Add-ons → Add-on Store → ⋮ → Repositories** y
pegá `https://github.com/astraware-dev/zonia-ha-addons`.

## Add-ons

- **[Zonia Tunnel](zonia-tunnel/DOCS.md)**: acceso remoto seguro a tu Home
  Assistant a través del servidor de Zonia. Necesitás el `tenant_id` y el
  `token` que te da Zonia.
